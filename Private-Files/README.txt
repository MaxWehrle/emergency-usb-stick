SENSITIVE FILES — instructions only; no vault is included

Do not place IDs, medical records, passwords, or other sensitive files unencrypted on the USB drive. This folder starts empty except for this guide.

One possible tool is Cryptomator (not bundled). Install and learn it before an emergency. Desktop vault instructions: https://docs.cryptomator.org/desktop/adding-vaults/ . Android local storage: https://docs.cryptomator.org/android/cloud-management/ . Android setup and license: https://docs.cryptomator.org/android/setup/ . Some Android versions or functions may require a paid license. Check the current app and your own device.

1. On Windows, create a new vault inside this private folder. Choose a long, unique password. Keep the password and recovery key away from the USB drive and public repository. Recovery instructions: https://docs.cryptomator.org/desktop/password-and-recovery-key/ .
2. Put a harmless TEST file in the open vault. Lock it, reopen it on Windows, and check the file.
3. Test the same vault from your actual Android phone and USB/file-manager setup. If you cannot open and read it, use another arrangement you have tested on both devices. Do not assume USB access.
4. Add sensitive files only after successful tests. Lock the vault after use. Check that no unencrypted copies remain elsewhere on the USB drive.
5. Copy the whole encrypted vault to a second USB drive in a separate place. Restore and read a test file from that copy on Windows and Android. Keep your password and recovery key separately in safe places. Losing both can make the files unreadable.

Encryption protects stored files. It does not replace backups or safe device use. Digital copies do not replace original documents.
