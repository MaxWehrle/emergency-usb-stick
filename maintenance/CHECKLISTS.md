# Öffentliche Prüfvorlagen

Kopieren Sie die passende Vorlage in einen Pull Request oder Prüfvermerk. Füllen Sie nur tatsächlich geprüfte Felder aus. Private Angaben von Hinweisgebern gehören nicht hierher.

## Quelle oder Lagekarte

| Feld | Eintrag |
|---|---|
| Land, Sprache, Region | |
| Karte und konkrete Aussage | |
| Zuständige Primärquelle, Herausgeber, URL | |
| Veröffentlichungsdatum der Quelle | |
| Abruf- und Prüfdatum | |
| Lizenz oder Nutzungsgrundlage | |
| Prüfer und fachliche Eignung | |
| Entscheidung und Begründung | |
| Offene, unbestätigte Angaben | |

**Regel:** Unbestätigte medizinische, sicherheitsrelevante oder regionalrechtliche Angaben nicht veröffentlichen.

## Hardware und Bezugsquelle

| Feld | Eintrag |
|---|---|
| Markt und Datum | |
| Produkt, Modell, Speichervariante | |
| Herstellerdatenblatt und Anschluss | |
| Händlerlink ohne Affiliate-Parameter | |
| Beobachteter Preis und Verfügbarkeit | |
| Selbst getestete Geräte und Ergebnis | |
| Nicht getestete Kompatibilität | |

**Regel:** Preis und Verfügbarkeit sind Momentaufnahmen; Herstellerangaben sind kein eigener Gerätetest.

## Release und Datenschutz

| Prüfung | Ergebnis / Beleg |
|---|---|
| Länderbranch und Commit | |
| Menschliche Quellenprüfung dokumentiert | |
| PDF/TXT und lokalisierte Ordner im ZIP-Wurzelverzeichnis | |
| ZIP entpackt, `START.html` offline geöffnet | |
| Suche, lokale Links, Textdateien geprüft | |
| Testmedium ergänzt und Datei zurückkopiert | |
| Schmale Ansicht, Windows und Android: tatsächlich getestete Geräte | |
| Git-Dateien, Historie und ZIP auf private Daten/Medien geprüft | |
| Lizenz und Quellenbasis geprüft | |
| Paket-Prüfsummen und ZIP-SHA-256 | |
| Tag, direkter Downloadlink und Abruf nach Veröffentlichung | |
| Offene Punkte und Freigabeentscheidung | |

**Regel:** Nicht durchführbare Tests ausdrücklich als offen kennzeichnen. Ein grüner technischer Audit ist keine fachliche Freigabe.
