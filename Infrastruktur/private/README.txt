VERTRAULICHE DATEIEN – Anleitung, kein Tresor

Dieser Ordner enthält ab Werk keine persönlichen Daten und keine Schlüssel. Legen Sie sensible Unterlagen nicht unverschlüsselt auf den Stick.

Ein möglicher Weg ist Cryptomator (nicht mitgeliefert). Installieren Sie die Anwendung vor einer Krise auf den Geräten, auf denen Sie den Tresor lesen möchten. Desktop-Anleitung: https://docs.cryptomator.org/desktop/adding-vaults/ . Android-Anleitung für lokalen Speicher: https://docs.cryptomator.org/android/cloud-management/ . Android-Varianten und Lizenzbedingungen: https://docs.cryptomator.org/android/setup/ . Für Schreibzugriff kann eine kostenpflichtige Lizenz erforderlich sein; prüfen Sie die aktuelle App-Version.

1. Erstellen Sie auf Windows in diesem Ordner einen neuen Cryptomator-Tresor. Wählen Sie ein langes, eigenes Passwort. Speichern Sie Passwort und Recovery Key NICHT hier und NICHT im Repository. Anleitung: https://docs.cryptomator.org/desktop/password-and-recovery-key/ .
2. Legen Sie zuerst eine harmlose TESTDATEI in den geöffneten Tresor, sperren Sie ihn und öffnen Sie ihn auf Windows erneut. Prüfen Sie, ob der Inhalt stimmt.
3. Testen Sie denselben Tresor auf Ihrem Android-Gerät mit Ihrer tatsächlich verfügbaren App und dem Dateimanager. Manche Geräte/Apps gewähren keinen Zugriff auf USB-Speicher oder öffnen HTML anders. Ist der Test erfolglos, planen Sie einen anderen auf beiden Geräten überprüften Weg. Verlassen Sie sich nicht auf angenommene Kompatibilität.
4. Kopieren Sie erst nach erfolgreichen Tests sensible Dateien hinein. Sperren Sie den Tresor nach Gebrauch. Achten Sie darauf, dass außerhalb des Tresors keine unverschlüsselten Kopien auf dem Stick liegen.
5. Kopieren Sie den gesamten verschlüsselten Tresor auf den zweiten Stick an einem getrennten Ort. Testen Sie die Wiederherstellung aus dieser Kopie auf Windows und Android. Bewahren Sie Passwort und Recovery Key getrennt an sicheren Orten auf; ohne beides können die Dateien dauerhaft unlesbar sein.

Ein verschlüsselter Tresor schützt Dateien im Ruhezustand. Er ersetzt keine sichere Bedienung des Computers und keine Backups. Digitale Kopien ersetzen Originale nicht.
